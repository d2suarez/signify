# Signify Help Desk

Ask for help with technology, the building, or anything else, and plan school projects together. Part of the Signify apps; everyone signs in with Signify ID.

- **Requests:** students and staff file tickets (with photos), follow them under My requests, and reply. Help desk agents work them from the dashboard: status, priority, assignment, internal notes, saved replies, devices with QR labels, recurring jobs, help articles, CSV export, Spanish on requester pages.
- **Projects:** anyone can start a project for an event, trip or rollout, add the people helping (staff or students), and plan it on a board, a list or a timeline, with milestones and updates.
- **From Teacher's Desk:** the Help desk tool sends a request without leaving the board.

See `CLAUDE.md` for how it is built and run.
